# Neuro-sama Lava Lamp Plugin 

[![pipeline status](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/badges/master/pipeline.svg)](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/commits/master)

## What is this?

This is a plugin for [OpenRGB](https://openrgb.org/) that synchronizes OpenRGB with Neuro-sama's lava lamp

* [Windows 32](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/jobs/artifacts/master/download?job=Windows%2032)
* [Windows 64](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/jobs/artifacts/master/download?job=Windows%2064)
* [Linux 32](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/jobs/artifacts/master/download?job=Linux%2032)
* [Linux 64](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/jobs/artifacts/master/download?job=Linux%2064)
* [MacOS ARM64](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/jobs/artifacts/master/download?job=MacOS%20ARM64)
* [MacOS Intel](https://gitlab.com/bw8686/openrgb-neuro-lava-lamp-plugin/-/jobs/artifacts/master/download?job=MacOS%20Intel)

## How do I install it?

* Download and extract the correct files depending on your system
* Launch OpenRGB
* From the Settings -> Plugins menu, click the "Install plugin" button
